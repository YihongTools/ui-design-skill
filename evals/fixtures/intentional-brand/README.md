# Intentional branding test fixture

This is a product brief, not proof that the page is good UI.

The hypothetical product's established identity uses a purple gradient in a header banner, rounded corners, and matching accent controls. The explicit product authority says **do not change that palette or gradient without a reason based on actual usability, contrast, or functionality**. An audit should not label the mere presence of purple, gradients, or rounded corners as an actionable defect.
